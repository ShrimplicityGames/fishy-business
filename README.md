# Fishy Business

A mobile-first aquarium business incremental game by Shrimplicity Games.

Build an aquatic empire across Earth, the Moon, Earth But Different, and FISH. Buy businesses, hire managers, collect Fish, unlock upgrades, and make increasingly irresponsible amounts of money.

## Play

Open the GitHub Pages site for this repository, or play the current release on [Neocities](https://shrimplicity-games.neocities.org/PLAY%20TEST%20GAMES/Fishy_Business).

## Project

- `index.html` and `Fishy Business/` contain the web release.
- `godot/` contains the Godot project source.

No real-money purchases are included.
